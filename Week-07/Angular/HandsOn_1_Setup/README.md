# Hands-On 1 — Environment Setup, Project Structure & First Component

## How to run
```
npm install
npm start        # ng serve -> http://localhost:4200
```

## What's included
- Angular 20 standalone-component workspace (angular.json, tsconfig*.json, package.json)
- notes.txt (Task 1, step 2 - file-purpose notes)
- HeaderComponent, HomeComponent, CourseListComponent, StudentProfileComponent (generated via `ng generate component ...` equivalents)
- app.component.html wired with <app-header> and <router-outlet>
