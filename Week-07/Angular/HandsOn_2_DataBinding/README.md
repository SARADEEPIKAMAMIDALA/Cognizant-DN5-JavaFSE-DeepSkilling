# Hands-On 2 — Data Binding, Lifecycle Hooks & Component Communication

## How to run
npm install && npm start

## What's included (builds on Hands-On 1)
- HomeComponent: interpolation, [disabled] property binding, (click) event binding, [(ngModel)] two-way binding, ngOnInit/ngOnDestroy logging
- CourseCardComponent: @Input() course, @Output() enrollRequested, ngOnChanges logging previous/current values
- CourseListComponent: renders 5 CourseCardComponents, handles (enrollRequested), shows selectedCourseId
